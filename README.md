# KAV Checker

Независимый центр аудита и отчётности Kaspersky Security Center. Подключается к базам Серверов администрирования KSC (Microsoft SQL Server) **только для чтения** и даёт удобные средства анализа: каталог установленных программ, поиск устаревших версий, уязвимости KSC, состояние защиты, события безопасности, контроль активности устройств, отчёты XLSX/CSV.

Продукт универсален: распространяется через Git, разворачивается в Docker, обновляется из GitHub через административную панель. Сведения о конкретной организации в репозиторий не входят.

## Возможности

- Несколько независимых источников KSC; выбранный источник запоминается для пользователя; диагностика подключения (версия SQL Server и KSC, наличие объектов, права учётной записи).
- Каталог программ: записи реестра KSC объединяются в продукты и ветки (Chrome, Firefox, Java, PHP, Python, OpenSSL и другие) с производителями, версиями и числом компьютеров; ручное исправление группировки.
- Проверка версий: программа из каталога и версия, ниже которой она устарела, — компьютеры и XLSX; несколько программ и источников, исключения, целевая версия; сравнение по правилам продукта (dpkg для пакетов Linux, числовое для Windows); сохранённые проверки.
- Уязвимости, найденные KSC: компьютеры по опасности, уязвимые программы, CVE и исправления.
- Состояние защиты: компьютеры без антивируса, с неработающей защитой, устаревшими базами, невылеченными объектами; версии KES и Агента.
- События безопасности: обнаружения, невылеченные объекты и сетевые атаки за период, динамика, журнал с поиском.
- Компьютеры: активность (глобальный фильтр «активные за последние N суток»), карточка с ПО, уязвимостями, защитой и событиями.
- Поиск в верхней панели (`/` или Ctrl+K): компьютер или программа текущего источника за одно действие.
- Локальные учётные записи, LDAP/LDAPS (несколько доменов, сертификаты CA, доступ по группам), второй фактор TOTP; роли администратор / аналитик / просмотр и доступ к отдельным источникам.
- Журнал действий, журнал событий, состояние системы; обновления из GitHub с проверками, резервной копией и автоматическим возвратом при ошибке; восстановление копии из браузера.

## Быстрый старт

```bash
git clone <репозиторий> /opt/kavcheck && cd /opt/kavcheck
./scripts/install.sh            # создаст .env с секретами и попросит проверить адрес, порт и каталог данных
./scripts/install.sh            # образы, миграции, запуск, локальный администратор (пароль печатается один раз)
sudo ./scripts/updater.sh install --yes   # помощник обновлений для кнопок «Обновить» и «Откатить» в браузере
```

Откройте приложение через свой reverse proxy с TLS (см. [docs/INSTALL.md](docs/INSTALL.md)), войдите локальным администратором, смените пароль, добавьте источник KSC в «Администрирование → Источники KSC» и нажмите «Проверить подключение».

## Требования

Linux-сервер с Docker Engine 24+ и Docker Compose v2, 2 ГБ ОЗУ, доступ к SQL Server базы KSC по TCP (порт 1433 по умолчанию) и отдельная учётная запись с ролью `db_datareader`.
