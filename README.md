# KAV Checker

Независимый центр аудита и отчётности Kaspersky Security Center. Подключается к базам Серверов администрирования KSC (Microsoft SQL Server) **только для чтения** и даёт удобные средства анализа: реестр установленного ПО, поиск программ и версий, группировка пакетов по продуктам и веткам версий (например, PHP), список компьютеров с выбранными версиями, контроль активности устройств, уязвимости KSC, отчёты XLSX/CSV.

Продукт универсален: распространяется через Git, разворачивается в Docker, обновляется из GitHub через административную панель. Сведения о конкретной организации в репозиторий не входят.

## Возможности первого выпуска

- Несколько независимых источников KSC с переключателем в верхней панели; проверка подключения с диагностикой (версия SQL Server, версия KSC, наличие объектов, права учётной записи).
- Реестр ПО как в KSC и логическая группировка по продуктам и веткам версий; встроенное проверенное правило для PHP; собственные правила.
- Выбор версий флажками, диапазон версий (алгоритм dpkg: 8.10 > 8.9), список компьютеров с фильтром активности (1/3/7/14/30 суток или произвольно), сохранение выбора как сценария аудита (CVE, описание, уровень).
- Компьютеры: имя, IP, ОС, группа, последнее подключение к KSC, статус активности, установленное ПО, продукты Kaspersky и статус KSC в карточке.
- Уязвимости, подтверждённые KSC, отдельно от пользовательских критериев.
- Конструктор отчётов, фоновое формирование с отменой, просмотр, экспорт XLSX (листы «Установки», «Версии», «Компьютеры», «Параметры») и CSV, шаблоны, повтор отчёта.
- Локальные учётные записи и LDAP/LDAPS с ролями администратор / аналитик / просмотр и доступом к отдельным источникам.
- Журнал действий, журнал событий, страница состояния системы, обновления и откат через GitHub, резервные копии внутренней базы.

## Быстрый старт

```bash
git clone <репозиторий> /opt/kavcheck && cd /opt/kavcheck
./scripts/install.sh            # создаст .env с секретами и попросит проверить адрес, порт и каталог данных
./scripts/install.sh            # образы, миграции, запуск, локальный администратор (пароль печатается один раз)
sudo ./scripts/updater.sh install --yes   # помощник обновлений для кнопок «Обновить» и «Откатить» в браузере
```

Откройте приложение через свой reverse proxy с TLS (см. [docs/INSTALL.md](docs/INSTALL.md)), войдите локальным администратором, смените пароль, добавьте источник KSC в «Администрирование → Источники KSC» и нажмите «Проверить подключение».

## Требования

Linux-сервер с Docker Engine 24+ и Docker Compose v2, 2 ГБ ОЗУ, доступ к SQL Server базы KSC по TCP (порт 1433 по умолчанию) и отдельная учётная запись с ролью `db_datareader`.

## Лицензия и шрифты

Шрифты Inter и Manrope (SIL OFL) входят в поставку; внешние ресурсы при работе не загружаются.
