## 2026-10-23 — первый выпуск 0.1.0

- Сделано: проект создан с нуля — backend (FastAPI, PostgreSQL, Alembic), адаптер KSC только для чтения, frontend (React/TS), авторизация (локальная, LDAP), роли, источники KSC, реестр ПО и группировка PHP, компьютеры, уязвимости, отчёты XLSX/CSV, журналы, Docker Compose, обновления/откат/резервные копии, CI, документация.

## 2026-10-23 — редизайн интерфейса

- Сделано: новая дизайн-система (графитовая панель, петролевый акцент, шрифты Onest и JetBrains Mono вместо Inter/Manrope), собственные пиктограммы, переработаны все страницы и состояния (загрузка, пусто, ошибка, успех), фирменный «спектр версий» с выбором веток и плавающей панелью действий, анимации с учётом reduced motion, клавиатурная работа меню, окон и вкладок, адаптивность до 390 px, согласованные светлая и тёмная темы.
- Основные файлы: `frontend/src/styles.css`, `frontend/src/components/ui.tsx` (новый), `components/Icons.tsx`, `Dialogs.tsx`, `Common.tsx`, `App.tsx`, `pages/**`, `frontend/public/fonts/`, `scripts/private-data.allow` (пространство имён w3.org).
- Результат: два прохода проверки в agent-browser (1440, 1280, 390 px, обе темы, окна, меню, выдвижная панель, вход); `tsc` и `vite build` без ошибок; 29 тестов backend проходят, 7 пропущены без синтетического SQL Server; проверка частных данных чистая; образ `web` пересобран.
- Известные проблемы: скрипт контекста Impeccable не запустился (права и окончания строк CRLF в установленном скилле), правила прочитаны вручную; около 80 встроенных стилей в страницах.

## 2026-10-24 — 0.2.0, этапы 1–2: аудит ПО, каталог, уязвимости, глобальный фильтр

- Сделано: сравнение версий по схеме продукта (dpkg для пакетов Linux, числовая для Windows, приведение нумерации Java и Python для Windows), условия «ниже / ниже или равна / равна / не ниже / выше / диапазон» и исключения версий и веток; автоматический каталог продуктов из реестра KSC (встроенные описания распространённых продуктов, автоматические группы, ветки, производители, ручные объединение, выделение и переименование), фоновая пересборка в worker; новый конструктор «Проверка версий» с несколькими программами и источниками, предварительный просмотр, отчёт XLSX/CSV с итогом по программам и источникам, сохранённые проверки с запуском одним действием; раздел «Уязвимости»: компьютеры по опасности, уязвимые программы, карточка компьютера; глобальный фильтр «Показывать компьютеры, активные за последние» (30 суток) в каталоге, реестре, компьютерах, уязвимостях и отчётах; выбранный источник запоминается для пользователя; крупная синтетическая база KAVBIG для проверки производительности.
- Основные файлы: `backend/app/ksc/{versions,catalog,catalog_build,vulns,queries}.py`, `backend/app/services/{catalog,cache}.py`, `backend/app/reports/audit.py`, `backend/app/api/{catalog,vulns,reports}.py`, миграция `0002_catalog_audit`, `frontend/src/pages/{CatalogPage,ProductPage,AuditBuilder,ReportsPage,VulnsPage}.tsx`, `frontend/src/components/ProductPicker.tsx`, `tests/ksc_synthetic/gen_bulk.py`.
- Результат: 45 тестов backend проходят (10 — на синтетическом SQL Server); миграция 0.1.0 → 0.2.0 на локальной базе прошла с сохранением отчётов; на KAVBIG (20 тыс. компьютеров, 600 тыс. установок, 660 тыс. обнаружений) каталог строится за 14 с, сводка уязвимостей без кэша — около 4 с, страницы из кэша — около 0,1 с; сценарии проверены в браузере на 1440 и 390 пикселях.
- Известные проблемы: первая сводка уязвимостей на очень больших базах занимает секунды (дальше — из кэша); новые записи реестра попадают в проверку после ближайшего обновления каталога.
