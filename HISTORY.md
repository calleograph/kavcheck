## 2026-10-24 — LDAPS: вход по короткому имени, выбор домена, диагностика входа

- Сделано: по сообщению владельца (на реальном AD при успешной проверке LDAPS вход отклонялся «Неверный логин или пароль») пересмотрен весь путь доменного входа. Пользователь вводит имя учётной записи без домена; оно ищется во всех включённых подключениях, при совпадении в нескольких доменах вход требует выбора домена (выбор на странице входа появляется при двух и более подключениях); `EXAMPLE\user` и UPN по-прежнему принимаются. Код результата поиска проверяется: Base DN не найден, ответ-ссылка на другой сервер, нет прав — «ошибка поиска», а не «неверный пароль»; переходы по ссылкам (referrals) в ldap3 отключены (по умолчанию библиотека шла к любому узлу с учётными данными, в том числе без TLS); фильтр в стиле 0.1.0 с `{login}` поддерживается. Причина отказа (с подключением, фильтром, DN) пишется в журнал событий и журнал действий; пользователю — общее сообщение. Исправлено смешение записей пользователей: одноимённый пользователь другого домена занимал существующую запись, совпадение с локальной учётной записью давало ошибку 500; теперь второй получает имя `имя@домен`. Раздел переименован в «LDAPS»; проверка подключения — только контроллер домена, новая «Проверка входа» проходит путь входа без сессии с причиной на каждом шаге.
