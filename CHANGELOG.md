# Журнал изменений

Для пользователей: что появилось и что изменилось в каждой версии. Версия задаётся файлом VERSION.

## [Unreleased]

- Вход доменных пользователей по LDAPS — по короткому имени учётной записи (например, `ivan.petrov`), без `@домен` и `ДОМЕН\`: имя ищется во всех настроенных доменах. Если одно имя есть в нескольких доменах, на странице входа выбирается домен; вход в «чужой» домен исключён.
- Раздел «LDAP» переименован в «LDAPS». Проверка подключения к контроллеру домена и проверка входа пользователя разделены: «Проверка входа» проходит тот же путь, что настоящий вход (поиск в каждом домене, пароль, группы, правила, второй фактор), и показывает причину на каждом шаге.
- Точная причина неудачного входа (пользователь не найден, ошибка поиска, пароль отклонён контроллером, нет разрешённой группы) — в журналах администратора; пользователь видит общее сообщение.

### Исправлено

- Ошибки поиска в каталоге (Base DN не найден, ответ-ссылка на другой сервер, нет прав) выдавались как «Неверный логин или пароль».
- Отключены переходы по ссылкам (referrals): библиотека LDAP могла повторять поиск на другом сервере с учётными данными сервисной записи, в том числе без TLS.
- Пользователь другого домена с тем же именем мог занять запись уже существующего пользователя KAV Checker; совпадение имени с локальной учётной записью приводило к ошибке входа.
- Фильтр пользователей в стиле 0.1.0 с подстановкой `{login}` не находил пользователей.

## [0.2.1] — 2026-10-24

Интерфейс по итогам аудита 0.2.0: быстрее найти нужное и получить отчёт; данные и совместимость с 0.2.0 не меняются, миграций нет.

- Поиск в верхней панели (`/` или Ctrl+K): компьютер или программа текущего источника — за одно действие.
- Проверка версий проще: на виду программа и версия, новейшая версия из каталога подставляется щелчком; целевая версия, охват компьютеров и группа — в дополнительных настройках.
- Главная: состояние источника строкой под заголовком, первым идёт блок «Защита и угрозы».
- Источники KSC: в форме сначала сервер, база и учётная запись; шифрование, тайм-ауты и выключение — в «Дополнительно»; основное действие — «Сохранить и проверить».
- Единый вид: полоса загрузки над таблицей при обновлении данных, плавное раскрытие блоков и смена страниц, уведомления справа внизу, стрелка у показателей, которые открывают список, движение без отскоков; имена компьютеров и угроз в таблицах не переносятся; группа «Администрирование» в меню сворачивается; у «Каталога программ» своя пиктограмма; кнопки в строках таблиц — одного спокойного вида.

### Исправлено

- Каталог программ показывал неверное число скрытых компьютеров (сумму по программам).
- В карточке компьютера была неверная подпись «Время — UTC»: время показано в часовом поясе пользователя.
- Спектры версий и активности не растягивались на всю ширину карточки.
- Не было видно фокуса клавиатуры на показателях-фильтрах и строках «Проблемы защиты».
- Склонение в строке о скрытых компьютерах («Скрыто 3 компьютера»).
- Во время пересборки каталога показывался ход прошлой сборки («обновляется: готово»).
- Уведомление о запуске проверки или отчёта пропадало: страница отчёта открывалась раньше, чем оно появлялось.
- Тёмная тема: уведомления, панель выбранных строк и плитка пользователя сливались с фоном.
- Склонение в панели выбранных строк («2 версии выбраны»).

## [0.2.0] — 2026-10-24

- Каталог программ: записи реестра KSC автоматически объединяются в продукты и ветки (Google Chrome, Firefox, Java, PHP, Python, OpenSSL и другие), с производителями, версиями и числом компьютеров; ошибочную группировку можно исправить вручную.
- Проверка версий: выберите программу и версию, ниже которой она устарела, — получите компьютеры и XLSX. Несколько программ и несколько серверов KSC в одной проверке; исключение версий и веток; целевая версия; проверку можно сохранить и запускать повторно.
- Сравнение версий учитывает тип продукта: пакеты Linux, программы Windows, нестандартная нумерация Java и Python.
- Раздел «Уязвимости» начинается с самых проблемных компьютеров; есть вид по уязвимым программам и карточка компьютера с CVE, KB и наличием исправления.
- Давно не подключавшиеся компьютеры скрыты в рабочих разделах (по умолчанию — неактивные дольше 30 суток), их можно показать одной кнопкой. Порог 7 суток из 0.1.0 заменён на 30.
- Выбранный источник KSC запоминается для каждого пользователя.
- Раздел «Состояние защиты»: компьютеры без антивируса, с неработающей защитой, устаревшими базами, невылеченными объектами, истёкшей лицензией, без свежей полной проверки и ожидающие перезагрузки; пороги баз и проверки выбираются на странице; версии Kaspersky Endpoint Security и Агента администрирования по числу компьютеров с переходом к списку; причины статуса KSC.
- Раздел «События безопасности»: обнаружения, невылеченные объекты, обработанные угрозы и сетевые атаки за сутки, 7 или 30 суток; динамика, компьютеры и угрозы с наибольшим числом событий, журнал обнаружений с поиском по компьютеру, угрозе, объекту и пользователю.
- Карточка компьютера: проблемы защиты в заголовке, вкладки «Установленное ПО», «Уязвимости» и «События безопасности».
- Главная: блок «Защита и угрозы» и частые задачи аудита.
- LDAP: несколько подключений (домены) с выбором основного, вход как `EXAMPLE\user` или `user@example.local`; загрузка корневых и промежуточных сертификатов ЦС (PEM, DER, текст) с проверкой срока и отказом принять закрытый ключ; доступ по группам каталога: группа → роль и источники KSC; поиск групп в каталоге; пошаговая диагностика (DNS, TCP, TLS, цепочка сертификатов, вход сервисной записи, поиск пользователя, группы) и проверка, какой доступ получит пользователь. Настройки LDAP из 0.1.0 переносятся автоматически.
- Второй фактор (TOTP, приложения-аутентификаторы) с резервными кодами; политика: отключён, по желанию, обязателен администраторам, всем или группам каталога; администратор может сбросить второй фактор пользователя.
- Работа за reverse proxy по HTTP и HTTPS: флаг Secure у cookie включается сам, когда адрес приложения — https:// (`COOKIE_SECURE=auto`).
- Обновления: проверки перед обновлением (место на диске, доступ к GitHub и реестрам, внутренняя база, возможность отката) — кнопкой и перед каждым обновлением; приложение останавливается на время резервной копии и миграций; при ошибке миграции база возвращается к копии, неудачная сохраняется под другим именем, код и образы — к прежней версии; отчёт о последнем обновлении с выполненными действиями; восстановление копии из браузера с подтверждением; хранятся образы текущей и одной предыдущей версии.
- Зеркала npm и pip для установки и обновления без доступа к официальным реестрам (`NPM_REGISTRY`, `PIP_INDEX_URL`, `install.sh --npm-registry`); проверка контрольных сумм пакетов сохраняется; локальные правки зеркала на сервере переносятся в `.env` при обновлении.
- Состояние системы: компоненты, процессор, память, диски, размер базы, отчётов, резервных копий и образов, ошибки фоновых задач, история обновлений, безопасность. Журнал событий: произвольный период и фильтр по компоненту.

- Проект открыт под лицензией MIT.
- Новый облик интерфейса: графитовое меню, единый акцент, шрифты Onest и JetBrains Mono, собственные пиктограммы.
- «Спектр версий»: доли версий и веток наглядно, выбор щелчком.
- Тема «как в системе» по умолчанию, светлая и тёмная выбираются в меню пользователя.
- Удобнее с клавиатуры и на телефоне: Escape и стрелки в меню и окнах, выдвижное меню, окна в виде нижнего листа.

### Исправлено

- Восстановление резервной копии поверх более новой схемы базы давало смешанную базу; теперь копия восстанавливается в чистую базу, прежняя сохраняется под другим именем.
- «Обновить» в разделе «Уязвимости» больше не перечитывает данные KSC при каждой следующей странице.

### Обновление с 0.1.0

- Если registry.npmjs.org недоступен с сервера, перед обновлением добавьте в `.env` строку `NPM_REGISTRY=<адрес зеркала>` (например, `https://npm-mirror.gitverse.ru`): обновление собирает интерфейс локально.
- Правки файлов проекта, сделанные на сервере вручную (например, адрес зеркала в `frontend/Dockerfile`), обновление 0.1.0 откладывает в `git stash`; после обновления адрес зеркала задаётся только в `.env`.
- Порог активности 7 суток, сохранённый в 0.1.0, заменяется на 30; другое значение сохраняется.
- Подключение LDAP из 0.1.0 и его группы ролей переносятся в новые подключения и правила доступа при первом запуске.
- Откат с 0.2.0 на 0.1.0 требует восстановления копии базы, снятой перед обновлением: Администрирование → Обновления → «Резервные копии» → «Восстановить», затем «Откатить версию».

## [0.1.0] — 2026-10-23

Первый выпуск.

- Административная панель: левое меню, верхняя панель с переключателем источника KSC, светлая и тёмная темы.
- Локальные учётные записи, LDAP/LDAPS, роли (администратор, аналитик, просмотр), доступ к отдельным источникам.
- Источники KSC: несколько подключений к SQL Server только для чтения, проверка с диагностикой (версия SQL Server, версия KSC, объекты, права).
- Реестр установленного ПО с поиском и счётчиками установок и уникальных компьютеров; группировка по продуктам и веткам версий; встроенное правило PHP.
- Выбор версий и диапазонов, список компьютеров с фильтром активности, сохранение сценариев аудита.
- Компьютеры и активность, карточка компьютера с ПО и продуктами Kaspersky; уязвимости, подтверждённые KSC.
- Отчёты: конструктор, фоновое формирование, отмена, повтор, шаблоны, экспорт XLSX и CSV.
- Журнал действий, журнал событий, состояние системы, обновления и откат через GitHub, резервные копии.
