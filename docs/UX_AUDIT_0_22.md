# UX-аудит 0.22.0: навигация, «Быстрый доступ», поиск

Аудит выполнен в браузере (agent-browser) на стенде от имени администратора и ролей «Просмотр» и «Аналитик»; карта функций и матрица соответствия — [FUNCTION_MAP.md](FUNCTION_MAP.md). Состав функций не менялся: изменился способ доступа.

## Что нашли и что сделали

| № | Находка | Серьёзность | Исправление |
|---|---|---|---|
| 1 | После входа — аналитическая «Главная» с десятками показателей: не отвечает на вопрос «куда идти» | высокая | Стартовая страница — «Быстрый доступ»; «Главная» сохранена целиком как «Обзор» (`/overview`) |
| 2 | Плоское меню: 13 пунктов и 21 вкладка администрирования подряд | высокая | Группы с раскрытием и запоминанием; администрирование — 6 подгрупп, «Развернуть все» / «Свернуть все» |
| 3 | Поиск находил только компьютеры и программы, требовал выбранный источник, не знал разделов и настроек | высокая | Поиск по названию и ключевым словам функций («исключения», «владелец», «лицензии», «импорт BI», «отчёт по уязвимостям»), пользователи, CVE, отчёты, категория с «Быстрого доступа» |
| 4 | Нужный отчёт — только внутри своего раздела; в «Отчётах» нет обзора видов | средняя | «Отчёты → Все виды отчётов» и готовые отчёты на «Быстром доступе» |
| 5 | Нет «последней работы» и показателей «куда смотреть» на входе | средняя | «Требует внимания» (кликабельные выборки) и «Последняя работа» |
| 6 | `/software` на ширине 390 px давал горизонтальную прокрутку (длинный текст ошибки каталога) | средняя, прежняя | перенос текста состояния каталога |
| 7 | При вложенной разметке меню подложка активного пункта сдвигалась; активный пункт мог оказаться вне видимой части меню | средняя | подложка считается от списка меню; открытый раздел прокручивается в видимую область |
| 8 | Показатели «Требует внимания» исчезали, если у источника нет основных итогов | низкая | источники показателей независимы |

## Сценарии (число действий)

| Сценарий | Было | Стало |
|---|---|---|
| Проблемные компьютеры | меню → «Состояние защиты» → фильтр: 3 | «Быстрый доступ» → «Проблемные компьютеры»: 1 |
| Сопоставление BI и KSC | меню → «Устройства» → вкладка: 3 | карточка на панели: 1 |
| Отчёт «Компьютеры без работающей защиты» | раздел → фильтр → «Сформировать отчёт»: 3–4 | карточка → формат: 2 |
| Найти настройку «Лицензии» | прокрутка списка из 21 пункта | `/` → «лицензии» → Enter: 3 нажатия, группа меню раскрывается сама |
| Найти CVE | поле поиска → «база уязвимостей»: 2–3 | `/` → CVE → Enter: категория первой |

## Проверено

Маршруты (41: меню, вкладки «Устройства», 21 вкладка администрирования, личные страницы) на 1440 и 390 px; ключевые — на 1920, 1366, 1280, 1024, 768, 390, 360: без горизонтальной прокрутки, ошибок страницы и ответов 4xx/5xx. «Быстрый доступ» — во всех четырёх темах на 1280 и 390 px. Роли: «Просмотр» не видит CVE Hunt, Pentest, иерархию, администрирование и действия с недоступными разделами. Персональная панель: порядок, удаление, возврат исходного набора, сохранение после перезагрузки.

## Ограничения

- Перетаскивание карточек — мышью; для клавиатуры есть кнопки «назад» и «вперёд».
- «Последняя работа» хранится в браузере (на каждом устройстве своя).
- Стенд не имеет доступного SQL Server KSC: показатели защиты на «Требует внимания» проверены по форме данных, а не по живым цифрам.
- Готовые отчёты по программам, зонам и иерархии открывают раздел (нужен выбор программы, зоны, подразделения), остальные — конструктор с условиями по умолчанию.
- Отдельной вкладки «Роли и права» нет: роли — в «Пользователи».
