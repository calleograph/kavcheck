# Отчёт по компьютеру

Кнопка «Сформировать отчёт» на карточке компьютера формирует быстрый отчёт `quick_hosts` с выбранным компьютером. Данные отчёта совпадают с карточкой: тот же источник KSC, те же правила подсчёта.

## Источник

Задание создаётся по источнику экрана, с которого оно запущено (заголовок `X-Source-Id`), а не по источнику, выбранному в сессии. Иначе идентификатор компьютера попадал бы в другую базу KSC: защита, уязвимости и EOL оказывались бы пустыми. Правило общее для всех быстрых отчётов (`api/reports.py`, `_page_source`).

## Состав и совпадение с карточкой

| Вкладка отчёта | Лист Excel | Что это | Совпадает с карточкой |
|---|---|---|---|
| Общие сведения | Компьютеры | имя, IP, ОС, группа, связь, статус KSC, краткие итоги по защите, ПО, уязвимостям, EOL, событиям, аппаратной части | — |
| Состояние защиты | Состояние защиты | проблемы защиты, антивирус, версия, постоянная защита, базы, полная проверка, причины статуса KSC | проблемы защиты (то же правило `ksc/protection.py`) |
| Установленное ПО | Установленное ПО | одна строка на установку | число записей |
| Уязвимости | Уязвимости | уязвимости KSC и по внешним базам (объединённый список `services/hostvulns.merge`): подтверждённые KSC, подтверждённые внешней базой, потенциальные | итоги по уровням опасности и всего |
| EOL | EOL | программы и ОС с окончанием поддержки (готовые результаты расчёта EOL по источнику) | число записей |
| События безопасности | События безопасности | события за 30 суток | число событий за 30 суток |
| Аппаратная часть | Аппаратная часть | сводка из инвентаризации Агента, предупреждения по ресурсам Linux-сервера | строка сводки |

Внешние базы учитываются по каждому компьютеру, как в карточке. Для выборки больше 50 компьютеров внешние базы не включаются, и отчёт говорит об этом прямо.

## Недоступные разделы

Раздел, которого нет на источнике, не выводится нулями:

* объектов уязвимостей KSC нет (проверка состава при подключении) — раздел «Уязвимости» не включается, в примечании названы недостающие объекты;
* расчёт EOL для источника ещё не выполнен — раздел «EOL» не включается, в примечании сказано, что это расчёт по расписанию;
* компьютер не найден в KSC — в примечании указано число таких компьютеров.

## Форматы

* HTML — вкладки как в карточке, поиск по таблице, сортировка по столбцу, порции строк («Показать ещё»), печать всех вкладок. Файл самодостаточен: стили и сценарий внутри, внешних ресурсов нет. Переключение вкладок работает и без сценариев.
* XLSX — лист на каждый раздел (см. таблицу), в каждом таблица полностью.
* CSV — основная таблица (компьютеры), как и у остальных отчётов.
* PDF — все таблицы в сокращённом виде с примечанием о пределе строк (полный набор — в XLSX).

## Проверка

`tests/test_host_report.py`: на синтетической базе KAVTEST для нескольких компьютеров сравниваются карточка и отчёт (ПО, уязвимости по итогам уровней, EOL, события, аппаратная часть, проблемы защиты), листы Excel и вкладки HTML; отдельно проверяется, что источник отчёта — источник страницы, и что недоступные разделы названы, а не показаны нулями. Запуск требует `KSC_TEST_HOST` (синтетическая база, см. `tests/ksc_synthetic/run.sh`).
