# Защитные продукты Kaspersky и состояние защиты

## Источники

| Что | Объект | Связь |
|---|---|---|
| Продукты Kaspersky на устройстве: версия, состояние, базы | `v_akpub_hst_prdstate` (над `hst_prdstates2`) | `nHost = v_akpub_host.nId` |
| Компоненты продукта | `v_akpub_prod_comp` | `nHostId = v_akpub_host.nId` |
| Установленные исправления | `v_akpub_hst_prdfix` | |
| Постоянная защита (сводно) | `v_akpub_host.nLastRtpState`, `nLastRtpErrorCode` | |
| Расширенный статус устройства | `v_akpub_host_status` | `nId = v_akpub_host.nId`, 1:1 |
| Обнаружено и не вылечено | `v_akpub_host.nVirusCount`, `nUncured` | |

## Продукты (`wstrProductNameId`, verified)

| Код | Продукт |
|---|---|
| `1093` | Сервер администрирования KSC — его `wstrProductBuildNumber` на устройстве `nHost = 1` даёт **версию KSC** |
| `1103` | Агент администрирования (версии 14.0, 14.2, 15.1 …) |
| `KES` | Kaspersky Endpoint Security для Windows; `wstrProductVersionId` — линейка (`11.0.0.0`), версия — **`wstrProductBuildNumber`** |
| `kesl` | Kaspersky Endpoint Security для Linux |
| `WSEE` | Kaspersky Security для Windows Server |

`bAvProduct = 1` — антивирусный продукт; `bHasRtp = 1` — обеспечивает постоянную защиту; `tmAvbasesDate` — дата баз (UTC).

## Перечисления (doc: klakdb)

`nState` продукта: 0 не запущен, 1 только что запущен, 2 инициализация, 3 запущен, 4 приостановлен, 5 деинициализация, 6 критическая ошибка, 7 завершает работу, 8 удаляется.

`nLastRtpState`: 0 неизвестно, 1 остановлена, 2 приостановлена, 3 запускается, 4 выполняется, 5 максимальная защита, 6 максимальная скорость, 7 рекомендуемые параметры, 8 пользовательские параметры, 9 сбой (`nLastRtpErrorCode`).

`v_akpub_host_status.nStatus`: 0 OK, 1 критический, 2 предупреждение. `nStatusMask` — биты причин:

| Бит | Маска | Причина |
|---|---|---|
| 0 | 1 | Агент в сети, но неактивен |
| 1 | 2 | постоянная защита не запущена |
| 2 | 4 | антивирус не запущен |
| 3 | 8 | слишком много вирусов |
| 4 | 16 | состояние постоянной защиты не соответствует заданному |
| 5 | 32 | антивирус не установлен |
| 6 | 64 | полная проверка давно не выполнялась |
| 7 | 128 | базы давно не обновлялись |
| 8 | 256 | Агент неактивен слишком долго |
| 9 | 512 | лицензия истекла |
| 10 | 1024 | много невылеченных объектов |
| 11 | 2048 | требуется перезагрузка |
| 12 | 4096 | несовместимые программы |
| 13 | 8192 | есть неустранённая уязвимость |
| 14 | 16384 | поиск обновлений Windows давно не запускался |
| 15 | 32768 | шифрование не соответствует требованиям |
| 17 | 131072 | есть необработанный инцидент |
| 19 | 524288 | мало места на диске |

Проверка бита: `(s.nStatusMask & 16384) <> 0`.

## Наблюдения

- Значения состояния отражают последний полученный отчёт устройства: оценивайте вместе с `tmLastNagentConnected`.
- Актуальность баз KSC оценивает относительно эталонной даты (`rpt_prd_avs_info.tmAvbasesDate`): 1 актуальны; 2, 3, 4 — отстают не больше 1, 3, 7 суток; 5 — старше 7 суток.
- Лицензии: `keys`, `keys_installed`, `keys_data`; на устройстве — бит 9 статуса.

## Как использует KAV Checker (раздел «Состояние защиты»)

Два чтения на источник (`queries.PROTECTION_HOSTS`, `PROTECTION_PRODUCTS`), сопоставление и проверки — в `ksc/protection.py`:

| Проблема | Условие |
|---|---|
| Нет антивируса | нет записей с `bAvProduct = 1` или бит 32 статуса |
| Защита не работает | у компьютера с антивирусом `nLastRtpState IN (1, 2, 9)`, или основной продукт в `nState IN (0, 4, 6, 7, 8)`, или биты 2/4 статуса |
| Невылеченные объекты | `nUncured > 0` или биты 8/1024 |
| Устаревшие базы | `tmAvbasesDate` основного продукта пуста или старше порога (1/3/7 суток) |
| Лицензия истекла | бит 512 |
| Нет свежей полной проверки | `tmLastFullScan` пуста или старше порога (7/30/90 суток), только при наличии антивируса |
| Требуется перезагрузка | бит 2048 |

Основной продукт — антивирусный с `bHasRtp = 1`, при нескольких — с самыми свежими базами. Версия продукта для спектра — `wstrProductBuildNumber`; Агент — код `1103`. Учитываются компьютеры, активные за порог глобального фильтра (`tmLastNagentConnected`); кластеры и подчинённые серверы исключаются по настройке отчётов.
