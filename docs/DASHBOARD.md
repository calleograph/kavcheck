# Главная страница и лицензии

Главная показывает, **сколько компьютеров действительно работает и защищается**, а не сколько исторических объектов накопилось в базе KSC. Основной показатель — активные компьютеры за выбранный период.

## Методика подсчёта

| Понятие | Как считается |
|---|---|
| **Активный компьютер** | Агент администрирования подключался к Серверу администрирования за последние N суток (`tmLastNagentConnected`). Периоды: 7, 30 (по умолчанию), 60, 90 суток; выбор запоминается в браузере. Это единственный признак активности |
| Всего объектов в KSC | все записи компьютеров источника (с учётом настройки «не считать подчинённые серверы»): склад, списанные, старые записи после переустановки, дубли |
| Серверы / станции | по названию ОС: «Windows Server …», «…Server», «Сервер» — сервер; остальные Windows и macOS — рабочая станция. Linux приходит в KSC как «Linux» без редакции, поэтому такие компьютеры показаны отдельно («тип ОС не определён»), а не причислены наугад |
| Защита установлена | у активного компьютера есть защитный продукт Kaspersky (и нет бита «антивирус не установлен») |
| Защищены | защита установлена, последнее достоверное состояние подтверждает работающую защиту, базы не старше 3 суток (в том числе у компьютера без связи) |
| Защита не работает | KSC сообщает, что защита остановлена. Приостановка и сбой (постоянная защита 2/9, продукт «приостановлен»/«критическая ошибка») учитываются всегда; «остановлена», «не запущен», «завершает работу» и биты статуса 2/4 — **только у компьютера на связи**: выключенный компьютер отчитывается именно так |
| Нет связи | активные за период компьютеры, которых KSC сейчас не видит (флаг «видимо»; нет флага — подключение Агента старше 30 минут). Время последнего подключения — в списке. Защита на них **не** считается остановленной |
| Состояние неизвестно | защита установлена, последний отчёт похож на остановку, но компьютер не на связи: отказ защиты и выключение не различить |
| Устаревшие базы | по фактической дате баз, независимо от связи |
| Без защиты | KSC сообщает «антивирус не установлен» либо Агент передавал сведения, а защитного продукта среди них нет; устройство без подключений Агента — нет данных, а не «без защиты» |
| Давно нет сведений | активные компьютеры, у которых KSC не обновлял сведения об устройстве дольше 7 суток |

**Связь и состояние антивируса — два независимых признака** (`ksc/protection.py`: `connected`, `stop_signal`, `rtp_off`, `state_unknown`, `no_av`). Число на главной, список по нажатию, раздел «Состояние защиты», зоны ответственности и отчёты используют одни и те же функции.

Признаки **раздельны и не заменяют друг друга**: «подключался к KSC», «виден в сети», «Агент установлен», «защитный продукт установлен», «защита работает», «лицензия». Таблица сравнения по периодам — в блоке «Как считается» страницы.

Число на карточке и список в боковой панели используют **один и тот же предикат** (`overview/calc.py`), поэтому всегда совпадают; отчёт «Сводка инфраструктуры» — те же числа.

## Источники и режим «Все источники»

* Для одного источника все показатели пересчитываются по его данным; «Все источники» суммирует независимые источники.
* Повторное подключение **одного и того же KSC** (совпадают сервер, порт и база) в итоги не входит — показывается предупреждение.
* Блок «Источники данных» показывает все доступные источники: выбранные — по живым данным, остальные — по **ежедневному срезу** (его раз в 6 часов делает worker, `overview/snapshots.py`) с временем получения. Срезы же рисуют график динамики (хранятся 400 суток).
* Нет достоверных данных (источник недоступен, расчёт зон ещё не выполнялся) — «Нет данных», а не ноль.

## Лицензии Kaspersky

Читает worker раз в 6 часов и по запросу (`licensing/service.py`, чтение — `ksc/licenses.py`).

* **Схема таблиц лицензий KSC зависит от версии и публично описана не полностью**, поэтому таблицы (`keys`, `keys_installed` и содержащие «lic» в имени) и столбцы определяются по каталогу базы: продукт, тип, срок действия, лимит, использовано, серийный номер. Бинарные столбцы и «данные ключа» не читаются никогда. Не удалось распознать — на странице «Нет данных», а в «Администрирование → Лицензии → Диагностика» видно, что найдено; значения можно внести вручную (запись подписана «вручную» и не заменяется чтением).
* **Ключи не хранятся и не показываются.** Серийный номер используется только для «отпечатка» (HMAC с мастер-ключом приложения), по которому один и тот же ключ на разных KSC считается один раз.
* **«Лимит действующих лицензий»** — сумма лимитов только тех лицензий, которые действуют **на сегодня** (действует, скоро истекает, бессрочная); срок пересчитывается при каждом запросе. Истёкшие остаются в подробном списке со статусом, но в сумму не входят. Лицензии с неизвестным сроком (дата не указана или нулевая) в сумму не входят и показываются отдельной строкой «Срок не указан». Бессрочная — дата 2100 года и позже в KSC либо отметка «Бессрочная» при ручном вводе. Действующих нет — лимит «0», а не «Нет данных».
* **«Свободно» и «Доля использования»** считаются по действующим лицензиям и только если использование известно по всем действующим; иначе «Нет данных» (частичная сумма не выдаётся за остаток).
* **Один ключ на нескольких KSC** (одинаковый отпечаток) считается один раз; если сроки на серверах разошлись (ключ продлён), берётся самый поздний. Ключи без серийного номера узнать на другом сервере нельзя — администратор может объединить их в пул вручную.
* **Общий пул:** лицензии с одним отпечатком либо объединённые администратором вручную считаются один раз — лимит общий, использование суммируется по серверам. Остальное — независимые лицензии источников, они суммируются. Лимиты в пуле различаются — берётся наибольший с пометкой. Данные KSC при объединении не меняются.
* **Недоступный источник не затирает лицензии:** если база KSC недоступна или таблицы лицензий не прочитаны, прежние записи остаются, а причина видна в «Администрирование → Лицензии»; пустой список сохраняется только когда чтение прошло успешно и лицензий нет.
* Использование неизвестно — «нет данных об использовании»; оно не подменяется числом активных компьютеров («занято лицензий» и «активные компьютеры» — разные величины).
* Проверено: синтетическая база SQL Server с условной структурой (`tests/ksc_synthetic/schema.sql`) и тесты определения столбцов. **На реальной KSC автоматическое определение столбцов не проверялось** — см. docs/VERIFY_REAL_SOURCES.md.

## Безопасность на главной

* Критические уязвимости, устройства с критическими, EOL ОС и программ, результаты Pentest — из готовых данных (подготовленные данные зон, результаты EOL, задания Pentest): главная не обращается к KSC ради них.
* Отчёт «Сводка инфраструктуры» (`quick_overview`): условия страницы (источники, период, показатель), краткий и подробный вид, XLSX, CSV, HTML, PDF.
