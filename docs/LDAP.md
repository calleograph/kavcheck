# Настройка LDAP / Active Directory

## Параметры

| Параметр | Active Directory | Другие каталоги |
|---|---|---|
| Протокол, порт | LDAPS 636 (глобальный каталог 3269) | LDAPS 636 или STARTTLS 389 |
| Base DN | `DC=example,DC=local` | корень поиска пользователей и групп |
| Bind DN | `CN=svc-kavcheck,OU=Service,DC=example,DC=local` или `svc-kavcheck@example.local` | DN сервисной записи |
| Фильтр пользователя | `(&(objectClass=user)(sAMAccountName={login}))` | например `(&(objectClass=inetOrgPerson)(uid={login}))` |
| Фильтр групп | `(objectClass=group)` | `(objectClass=groupOfNames)` |
| Атрибуты | `sAMAccountName`, `displayName`, `mail`, `objectGUID` | `uid`, `cn`, `mail`, `entryUUID` |
| Вложенные группы | включить (правило LDAP_MATCHING_RULE_IN_CHAIN) | выключить, если каталог не поддерживает |

Сертификат: при «Проверять сертификат сервера» цепочка проверяется по системным ЦС; для корпоративного ЦС вставьте корневой сертификат в поле «Сертификат ЦС (PEM)».

## Как проходит вход

1. Логин проверяется среди локальных учётных записей (локальный администратор всегда работает).
2. Сервисная запись ищет пользователя по фильтру; найденный DN выполняет bind с введённым паролем. Пароль не сохраняется.
3. Читаются группы (с вложенными) и по DN групп ролей определяется роль. Пользователь без роли не допускается.
4. Создаётся или обновляется локальное представление пользователя (логин, имя, почта, роль), открывается серверная сессия.

Отключение учётной записи в каталоге блокирует вход; отключение в KAV Checker (Пользователи) — тоже, независимо от каталога.

## Проверка

Кнопка «Проверить подключение» выполняет диагностику по этапам и, с тестовым логином и паролем, показывает, какую роль получит пользователь и в какие группы он входит. Тестовые данные не сохраняются; проверка записывается в журнал действий без пароля.
