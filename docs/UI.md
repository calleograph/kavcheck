# Интерфейс KAV Checker: аудит и единый подход

Документ для разработчиков интерфейса: что было найдено при аудите и по каким правилам строятся экраны. Токены и компоненты — в `frontend/src/styles.css` и `frontend/src/components/`.

## Аудит 0.2.0

Проверено 24.10.2026: все разделы на 1440 и 390 пикселях, светлая и тёмная темы, сценарии «найти устаревшие версии», «открыть компьютер», «разобрать проблему защиты», «добавить источник KSC». Данные — синтетическая база на 20 тыс. компьютеров.

| 13 | Уведомления | Появлялись внизу по центру поверх панели выбранных строк и исчезали рывком | низкая | Справа внизу, с появлением и уходом |

Что работает и сохраняется: токены цвета и размеров, светлая и тёмная темы, собственные пиктограммы одного штриха, скелеты загрузки, «спектр версий», клавиатура в меню и окнах, `prefers-reduced-motion`, отсутствие горизонтальной прокрутки страницы на 390 px.

## Аудит 0.2.1 на реальной базе KSC

По замечаниям владельца после проверки на реальной базе (24.10.2026) и повторного прохода по всем разделам.

| № | Где | Проблема | Решение |
|---|---|---|---|
| 1 | Каталог | Поиск «php» выдаёт PHP, php-pear, php-xml, php-gd, php-mbstring, php-ldap отдельными строками — работать с ними как с набором нельзя | Семейства: основной продукт и компоненты (универсально по названию), раскрытие в каталоге, подпись семейства в поиске |
| 2 | Каталог, проверка версий | Нет выбора нескольких программ; каждая программа — отдельный переход в конструктор | Отметки в каталоге (программа, несколько, семейство), выбор сохраняется между разделами, «Проверить версии» и «Отчёт по установкам» из панели выбранного |
| 3 | Все списки | Кнопки страниц; на возврате из карточки — снова первая страница без фильтров | Непрерывные списки с подгрузкой и виртуализацией, фильтры и место прокрутки сохраняются |
| 4 | Карточка продукта | «Компьютеры» у версии раскрывали список внизу страницы — казалось, что кнопка не сработала | Боковая панель рядом с местом щелчка; состояние в адресе, «Назад» из карточки компьютера к ней возвращает |
| 5 | Везде | Крупные отступы, строки и поля: много прокрутки | Компактная сетка: строки таблиц ниже, отступы и поля меньше; на сенсорных экранах элементы остаются крупными |
| 6 | Проверка версий | Конструктор занимал больше экрана | Программа и версия в одной строке, остальное — по запросу; основные действия видны без прокрутки |
| 7 | Состояние защиты | «Активен за 30 суток» выдавался за наличие проблемы сейчас; выключенные устройства смешивались с работающими | «Только онлайн» по флагу KSC «видимо в сети» (по умолчанию), колонка «Онлайн», «нет данных» без флага |
| 8 | Защита, события, уязвимости | Щелчок по показателю или проблеме менял список далеко за пределами экрана | Прокрутка к списку-результату; переход «Компьютеры» из уязвимых программ — к началу вкладки |
| 9 | Карточка компьютера | Список программ обрезался на 1 000 записях | Полный список с виртуализацией |
| 10 | Проверка версий | Быстрый результат — первые 300 строк | Все строки (в пределах `max_rows`) непрерывным списком; пакеты и версии «найдено / подходит» по каждой программе |

## Единый подход

### Принципы

- **Одно основное действие на экране** — кнопка `.btn.primary`. Остальные — обычные или «тихие» (`.btn.ghost`).
- **Сначала нужное, потом настройки.** Обязательные поля видны, технические (тайм-ауты, пороги, шаблоны SQL) — в `<details class="disclosure">` «Дополнительно» с понятными значениями по умолчанию.
- **Число ведёт к списку.** Показатель, по которому можно отобрать компьютеры, — кнопка или ссылка (`.meter-btn`, `.meter-link`), фильтр сохраняется в адресе.
- **Состояние видно всегда.** Загрузка — скелет или полоса над таблицей, ошибка — `.alert.error` с текстом, пусто — `Empty` с подсказкой, что сделать.
- **Слова пользователя.** Кнопка называет действие («Найти устаревшие версии», «Сохранить и проверить»), уведомление повторяет его итог.
- **Результат рядом с действием.** Щелчок по числу или версии открывает боковую панель; фильтр из показателя прокручивает к списку. Изменения за пределами экрана без прокрутки к ним не допускаются.
- **Список непрерывный.** Никаких кнопок страниц: порции подгружаются при прокрутке, «Назад» возвращает на то же место с теми же фильтрами.
- **Выбор сохраняется.** Отмеченные программы живут до явного «Снять выбор» и не теряются при переходах.

### Основа

- Цвет: холодное нейтральное полотно, графитовая панель навигации, один акцент `--accent`; статусы `--ok`, `--warn`, `--danger` только для состояния, не для украшения.
- Шрифты: Onest — интерфейс; JetBrains Mono — версии, IP-адреса, CVE, угрозы, пути. Шкала 12 / 13 / 14 / 16 / 19 / 24 px, числа — табличные.
- Отступы: внутри карточки 18 px, между блоками 16 px, перед заголовком раздела 28 px. Радиусы: 4 — метки, 8 — кнопки и поля, 12 — карточки и таблицы.

### Компоненты

| Задача | Компонент |
|---|---|
| Заголовок страницы и её действия | `PageHead` |
| Ключевые числа | `.meters` с `.meter` (`.meter-btn` — фильтр, `.meter-link` — переход) |
| Фильтры над таблицей | `.toolbar`: поиск `.grow`, поля `.w-md`, `Segmented`, переключатель; активные фильтры — `.chip` в `.toolbar-foot` |
| Таблица | `.table-scroll` + `.table`; `is-busy` — идёт загрузка; `.hide-sm` — столбец скрывается до 700 px; `SortTh` — сортировка |
| Длинный список | `useInfinite` + `VirtualRows` + `ListFoot` (`components/Infinite.tsx`); фильтры — `useKept` |
| Компьютеры по щелчку на числе или версии | `HostsDrawer` (боковая панель, состояние в адресе) |
| Выбор программ | `useSelection` (`selection.ts`) + `SelectionDock` |
| Доли версий и состояний | `Spectrum` |
| Состояние | `.badge` (ok, warn, err, accent), `.dot` |
| Подтверждение опасного действия | `ConfirmDialog` (`typed` — для необратимых) |
| Короткий итог действия | `useToast` |
| Действия над выбранными строками | `Dock`; для отчётов — `useRowSel` + `ReportDock` + `CheckAll` (`components/QuickReport.tsx`) |
| Отчёт из раздела: предпросмотр и выгрузка | `QuickReportPanel` (боковая панель: число компьютеров, условия, замечания, предпросмотр, «Дополнительно», Excel/HTML/CSV) |

### Таблицы

- Имена компьютеров, угроз, версии и IP-адреса не переносятся; длинные пути обрезаются многоточием с полным значением в подсказке.
- Строка, открывающая карточку, — `.clickable` со ссылкой внутри (для клавиатуры и средней кнопки мыши).
- Под таблицей — `ListFoot` («Показано N из M», подгрузка); в рабочих разделах — `HiddenNote` о скрытых неактивных компьютерах.

### Движение

- 120–180 мс — отклик на наведение и нажатие; 200–300 мс — смена состояния (вкладки, сегменты, раскрытие, окно); не дольше 650 мс — единственное «авторское» появление спектра.
- Кривая `--ease-out`; уход быстрее появления.
- Страница и новые строки таблицы появляются коротким растворением; раскрывающиеся блоки (`details`) меняют высоту плавно там, где браузер это поддерживает.
- При `prefers-reduced-motion` перемещения и масштаб отключаются, остаются смена прозрачности и цвета.

### Адаптивность

- До 960 px — выдвижное меню; до 700 px — окна снизу листом, поля фильтров во всю ширину, второстепенные столбцы скрыты, поиск в верхней панели открывается кнопкой.
- Страница не прокручивается по горизонтали на 390 px; широкие таблицы прокручиваются внутри своего контейнера.
