# Интерфейс KAV Checker: аудит и единый подход

Документ для разработчиков интерфейса: что было найдено при аудите и по каким правилам строятся экраны. Токены и компоненты — в `frontend/src/styles.css` и `frontend/src/components/`.

## Единый подход

### Принципы

- **Одно основное действие на экране** — кнопка `.btn.primary`. Остальные — обычные или «тихие» (`.btn.ghost`).
- **Сначала нужное, потом настройки.** Обязательные поля видны, технические (тайм-ауты, пороги, шаблоны SQL) — в `<details class="disclosure">` «Дополнительно» с понятными значениями по умолчанию.
- **Число ведёт к списку.** Показатель, по которому можно отобрать компьютеры, — кнопка или ссылка (`.meter-btn`, `.meter-link`), фильтр сохраняется в адресе.
- **Состояние видно всегда.** Загрузка — скелет или полоса над таблицей, ошибка — `.alert.error` с текстом, пусто — `Empty` с подсказкой, что сделать.
- **Слова пользователя.** Кнопка называет действие («Найти устаревшие версии», «Сохранить и проверить»), уведомление повторяет его итог.

### Основа

- Цвет: холодное нейтральное полотно, графитовая панель навигации, один акцент `--accent`; статусы `--ok`, `--warn`, `--danger` только для состояния, не для украшения.
- Шрифты: Onest — интерфейс; JetBrains Mono — версии, IP-адреса, CVE, угрозы, пути. Шкала 12 / 13 / 14 / 16 / 19 / 24 px, числа — табличные.
- Отступы: внутри карточки 18 px, между блоками 16 px, перед заголовком раздела 28 px. Радиусы: 4 — метки, 8 — кнопки и поля, 12 — карточки и таблицы.

### Компоненты

| Задача | Компонент |
|---|---|
| Заголовок страницы и её действия | `PageHead` |
| Ключевые числа | `.meters` с `.meter` (`.meter-btn` — фильтр, `.meter-link` — переход) |
| Фильтры над таблицей | `.toolbar`: поиск `.grow`, поля `.w-md`, `Segmented`, переключатель; активные фильтры — `.chip` в `.toolbar-foot` |
| Таблица | `.table-scroll` + `.table`; `is-busy` — идёт загрузка; `.hide-sm` — столбец скрывается до 700 px; `SortTh` — сортировка |
| Доли версий и состояний | `Spectrum` |
| Состояние | `.badge` (ok, warn, err, accent), `.dot` |
| Подтверждение опасного действия | `ConfirmDialog` (`typed` — для необратимых) |
| Короткий итог действия | `useToast` |
| Действия над выбранными строками | `Dock` |

### Таблицы

- Имена компьютеров, угроз, версии и IP-адреса не переносятся; длинные пути обрезаются многоточием с полным значением в подсказке.
- Строка, открывающая карточку, — `.clickable` со ссылкой внутри (для клавиатуры и средней кнопки мыши).
- Постраничный вывод — `Pager` под таблицей; под таблицей рабочих разделов — `HiddenNote` о скрытых неактивных компьютерах.

### Движение

- 120–180 мс — отклик на наведение и нажатие; 200–300 мс — смена состояния (вкладки, сегменты, раскрытие, окно); не дольше 650 мс — единственное «авторское» появление спектра.
- Кривая `--ease-out`; уход быстрее появления.
- Страница и новые строки таблицы появляются коротким растворением; раскрывающиеся блоки (`details`) меняют высоту плавно там, где браузер это поддерживает.
- При `prefers-reduced-motion` перемещения и масштаб отключаются, остаются смена прозрачности и цвета.

### Адаптивность

- До 960 px — выдвижное меню; до 700 px — окна снизу листом, поля фильтров во всю ширину, второстепенные столбцы скрыты, поиск в верхней панели открывается кнопкой.
- Страница не прокручивается по горизонтали на 390 px; широкие таблицы прокручиваются внутри своего контейнера.
