# Антивирусная защита сотрудников

Раздел показывает, как Kaspersky защищает известные компьютеры сотрудников. Доступен администратору и специалисту по ИБ с доступом ко всем источникам KSC, иерархии и полной области инвентаризации. Текущий источник в верхнем меню не меняет охват сводки.

## Подготовка данных

1. Выполните проверку в «Аудите домена» и проверьте охват учётных записей и правила их классификации. Знаменатель отчёта — уникальные включённые пользовательские записи из последней успешной проверки выбранного каталога AD. Проверка действует 45 суток. Отключённые, просроченные, технические, сервисные, тестовые и неклассифицированные записи исключаются. При совпадении идентификатора AD используется одна запись. Неоднозначные логины и рабочие адреса не участвуют в сопоставлении.
2. Департамент, должность, путь подразделения и дата создания записи берутся из аудита. Название организации дополняется из свежего снимка LDAPS раздела «Иерархия предприятия» по однозначному рабочему адресу. Пустое значение означает отсутствие надёжного источника. Для точного списка штатных сотрудников, охвата нескольких независимых каталогов и сверки с кадровыми переводами или увольнениями нужен актуальный кадровый список. Готовый срез AD описывает только охват выбранной проверки.
3. Используются назначенный пользователь и владелец карточки инвентаризации, актуальные закрепления из BI и однозначные наблюдения сеанса KSC за последние 30 суток. Сеанс показывает использование компьютера. IP, ФИО, сходное имя компьютера и последний пользователь сами по себе связи не создают. Подтверждённые назначения уточняются в карточке учёта или при сопоставлении BI и KSC. При сборе сводки эти назначения сохраняются.
4. Защита, ОС, IP и подключение читаются из подготовленных данных KSC. Зоны — из действующих назначений зоны и учётных сведений. Устройства считаются по устойчивому идентификатору. Для KSC это пара «источник + ID компьютера». Записи BI и инвентаризации объединяются с записью KSC по подтверждённой связи. Общее устройство может участвовать в оценке нескольких сотрудников, в числе устройств оно учитывается один раз.

После новой проверки AD сводка пересчитывается автоматически. При неизменной проверке worker обновляет её раз в шесть часов. Администратор может запросить пересчёт на странице. Состояние и предупреждения о покрытии видны рядом с датой среза. Сборка, страницы и Excel используют внутреннюю базу Ковчега. Новых подключений к корпоративным источникам не требуется.

## Расчёт показателей

- «Есть антивирус Kaspersky» означает свежее подтверждение установки хотя бы на одном устройстве сотрудника. Сюда входят устройства с проблемами и устройства, для которых работу защиты ещё нужно проверить.
- «Полностью защищены» означает, что на всех известных компьютерах есть свежие сведения о работающей постоянной защите и актуальных базах. Их давность проверяется по общему порогу активности. Порог возраста антивирусных баз — три дня. Если защита подтверждена у части известных компьютеров, состояние — «Частично защищены».
- «Подтверждено отсутствие Kaspersky» присваивается при свежем явном признаке отсутствия управляемого антивируса в KSC у каждого известного устройства, если данные о продукте этому не противоречат. Наличие других антивирусных продуктов отчёт не определяет.
- Проблемы установленного продукта, устаревание, отсутствие связи с KSC, недостающие сведения и отсутствие связи с оборудованием показываются отдельно. В строке можно увидеть причину. Графа принадлежности заполняется по явному признаку из BI или по учётному номеру, когда иных данных нет. При противоречии используется «Не определено».

Числа и проценты относятся к текущей выборке уникальных сотрудников. Фильтры устройства выбирают сотрудников, у которых есть подходящий связанный компьютер. Их итоговая оценка по-прежнему учитывает все известные устройства. Вкладки «Сотрудники» и «Устройства» связаны переходами из показателей и строк. У сводки, текущей вкладки и боковой выборки устройств есть своё действие «Сформировать отчёт». Сводка выгружает показатели и распределения по состоянию защиты, департаментам и ОС. Подробный Excel выгружает полную выборку в пределах установленного лимита отчётов. Файл содержит персональные данные.
