# KAV Checker — текущее состояние проекта

Документ описывает только актуальное состояние. Журнал изменений по датам — [HISTORY.md](HISTORY.md); изменения для пользователей — [CHANGELOG.md](CHANGELOG.md).

## Назначение

Независимый центр аудита и отчётности Kaspersky Security Center (KSC). Подключается к базам Серверов администрирования KSC на Microsoft SQL Server **только для чтения** и даёт: каталог установленных программ (продукты, ветки, версии), поиск устаревших версий по нескольким программам и источникам, уязвимости KSC, состояние защиты, события безопасности, контроль активности устройств, отчёты XLSX/CSV. Лицензия MIT, репозиторий публичный (github.com/calleograph/kavcheck). Продукт универсален (без данных конкретной организации), ставится в Docker, обновляется из GitHub.

Пользователи: специалисты информационной безопасности и системные администраторы; рабочий инструмент с высокой плотностью данных, используется ежедневно.

## Архитектура

| Сервис (compose) | Технология | Роль |
|---|---|---|
| `web` | nginx unprivileged + React/TypeScript SPA (Vite) | статика, прокси `/api/`, CSP |
| `backend` | Python 3.12, FastAPI, SQLAlchemy async, Alembic | API, вход (локальный, LDAPS, TOTP), роли, источники KSC, данные, отчёты (постановка), настройки, журналы, состояние системы |
| `worker` | тот же образ (`python -m app.worker`) | фоновые отчёты (`report_jobs`), построение каталога программ (`CatalogScheduler`), пульс в `service_heartbeats` |
| `postgres` | PostgreSQL 16 | внутренняя база |

Базы KSC читаются драйвером pymssql через шаблоны `backend/app/ksc/queries.py` с защитой `guard.py`. Тяжёлые агрегаты (уязвимости, состояние защиты, события) кэшируются в памяти процесса (`services/cache.py TtlCache`, `CACHE_TTL_SECONDS`). Обновления из браузера — через помощника на хосте `scripts/updater.sh` (канал `DATA_ROOT/updater`).

## Технологии и зависимости

Backend: fastapi, uvicorn, SQLAlchemy 2, asyncpg, alembic, pydantic 2, ldap3, cryptography (AES-GCM, X.509), argon2-cffi, pymssql, openpyxl, segno (QR-код TOTP). Frontend: React 19, react-router-dom 7, TypeScript 5, Vite 6, `@tanstack/react-virtual` 3.14.10 (только виртуализация строк, без разметки); без UI-библиотек и графиков, пиктограммы — собственный набор SVG. Разделы кроме главной загружаются по требованию (`React.lazy`). Docker Engine + Compose v2.

## Дизайн-система интерфейса

- Направление «приборная панель аудитора»: графитовая боковая панель (`--chrome`), светлое холодное полотно, один акцент — петролевый `--accent` (#0f6a8b; в тёмной теме #5ec8e5), статусы ok/warn/danger, шкала `--sp-0…7` для версий.
- Шрифты: Onest — интерфейс; JetBrains Mono — версии, IP-адреса, CVE, имена угроз, пути, команды. Числа — `tabular-nums`.
- Фирменный элемент — «спектр версий» (`Spectrum`): доли версий и веток, щелчок выбирает. В «Состоянии защиты» — спектры версий KES и Агента и «реестр проблем» (`.ledger`) с долями; в «Событиях» — столбчатая динамика без библиотек (`.trend`).
- Показатели (`.meters`) бывают кнопками-фильтрами (`.meter-btn`, `aria-pressed`) и ссылками (`.meter-link` на главной); при наведении и фокусе у них появляется стрелка.
- Правила экранов — [docs/UI.md](docs/UI.md): одно основное действие, технические параметры в «Дополнительно», полоса загрузки над таблицей (`.table-scroll.is-busy`), идентификаторы в таблицах не переносятся. Поиск в верхней панели (`GlobalSearch`, `/` и Ctrl+K) — компьютеры и программы текущего источника.
- Движение: 120–300 мс, кривая `--ease-out` или `--ease-snap` без отскока; страница и новые строки появляются растворением, `details.disclosure` раскрывается плавно (Chromium 131+), уведомления справа внизу с уходом.
- Темы «как в системе»/светлая/тёмная; `prefers-reduced-motion`; видимый фокус, ловушка фокуса в окнах; группа «Администрирование» в меню сворачивается (`kc:nav-admin` в localStorage); до 960 px — выдвижное меню, до 700 px — окна нижним листом, поиск открывается кнопкой, второстепенные столбцы скрыты; таблицы прокручиваются внутри контейнера, страница не прокручивается по горизонтали на 390 px.

## Реализованные функции (0.2.0)

- Оболочка, темы, страницы 404 и «нет источника»; выбранный источник хранится у пользователя (`users.current_source_id`).
- Вход: локальные учётные записи (проверяются первыми, работают при любом состоянии LDAPS); доменные — по LDAPS по короткому имени учётной записи (sAMAccountName) без домена: имя ищется во всех включённых подключениях, совпадение в нескольких доменах — выбор домена на странице входа (`/auth/login-options`, поле `domain` при входе); прежние формы `EXAMPLE\user` и UPN принимаются; одноимённые пользователи разных доменов — разные записи (`имя@домен`); сертификаты CA с проверкой, правила доступа группа → роль и источники, поиск групп; проверка подключения (контроллер домена) и проверка входа (тот же путь, что вход, без сессии) раздельно; точная причина отказа — в журналах администратора; TOTP с резервными кодами и политикой, сброс администратором; роли admin/analyst/viewer, доступ к источникам, защита от перебора, CSRF, Secure-cookie по HTTPS автоматически.
- Источники KSC: CRUD, диагностика, совместимость по функциям.
- Программы: каталог (встроенные описания ~70 продуктов + автоматические группы, ветки, производители, ручные объединение/выделение/переименование; семейства — основной продукт и связанные компоненты по префиксу названия, `catalog_build.families`), выбор программ и семейств с сохранением между разделами, «Отчёт по установкам», карточка продукта (компьютеры версии или ветки — в боковой панели), производители, реестр KSC.
- Проверка версий (`version_audit`): несколько программ и источников; пункт может охватывать несколько продуктов (`product_keys`, семейство); условия lt/le/eq/ge/gt/range/any, исключения, целевая версия, сравнение по схеме каждой записи; найденные пакеты и версии с признаком «подходит» (сводка, лист XLSX «Найденные пакеты»), продукт каталога у строк; предпросмотр всех строк, фоновый XLSX/CSV, сохранённые проверки.
- Уязвимости KSC: компьютеры по опасности, уязвимые программы, карточка компьютера.
- Состояние защиты: «Только онлайн» по флагу KSC «видимо в сети» (по умолчанию; применяется до подсчёта), колонка «Онлайн»; проблемы (нет антивируса, защита не работает, невылеченные объекты, устаревшие базы, лицензия, полная проверка, перезагрузка) с порогами, версии KES/KESL/Агента, причины статуса KSC.
- События безопасности: сводка за 1/7/30 суток, динамика, топ компьютеров и угроз, журнал обнаружений с поиском и фильтрами.
- Компьютеры: список с глобальным фильтром активности и счётчиком скрытых; карточка со статусом KSC, проблемами защиты, продуктами Kaspersky и вкладками ПО, уязвимостей и событий.
- Главная: состояние источника строкой под заголовком, блок «Защита и угрозы», компьютеры и программы с активностью, последние отчёты, частые задачи.
- Поиск в верхней панели: компьютеры по имени и DNS-имени, программы каталога; переход в карточку или в список раздела с запросом.
- Отчёты: фоновое формирование с ходом выполнения и отменой, повтор, шаблоны, XLSX/CSV/HTML.
- Быстрые контекстные отчёты (после 0.2.2, не выпущено): выбор строк флажками в «Уязвимостях» (список KLA/CVE, программы, компьютеры), «Компьютерах», «Состоянии защиты», «Событиях», каталоге и конструкторе проверки версий → боковая панель с предпросмотром (`POST /quick/preview`) и выгрузкой XLSX/HTML/CSV; виды `quick_vulns|quick_hosts|quick_protection|quick_events`; единый документ `reports/quick.py`, выгрузки `reports/quick_export.py`; подсчёт без двойного учёта (уникальные компьютеры, установки, обнаружения); «связь за N суток» и «в сети сейчас» — разные условия. - Администрирование: состояние системы (компоненты, ресурсы, диски, размеры, ошибки, история обновлений, безопасность), источники, пользователи и политика второго фактора, LDAPS, общие настройки, каталог программ, обновления (проверки перед обновлением, журнал, отчёт последнего обновления, откат, резервные копии, восстановление с подтверждением), журнал событий с периодом и компонентами, журнал действий.
- Обновление: проверки, остановка приложения перед копией, автоматический возврат базы и версии при ошибке миграции или запуска, хранение образов текущей и предыдущей версии, точное восстановление копии в чистую базу, зеркала npm/pip.

## Известные ограничения

- Не проверено на реальной базе KSC и реальном каталоге Active Directory (только синтетические KAVTEST, KAVBIG и тестовый OpenLDAP); Windows-авторизация к SQL Server не проверена. По сообщению владельца (24.10.2026), на реальном AD вход по LDAPS отклонялся «Неверный логин или пароль» при успешной проверке подключения; исправления 24.10 (коды результата поиска, отключённые referrals, причины в журнале, проверка входа) ждут проверки на реальном AD.
- Первая сводка уязвимостей и состояния защиты на очень больших базах занимает секунды; кэш — в памяти процесса backend (сбрасывается при перезапуске, не общий для нескольких реплик).
- Новые записи реестра попадают в каталог после ближайшей пересборки (проверка изменений каждые 15 минут).
- В «Событиях» топ компьютеров считается за период целиком; события удалённых устройств показываются без имени (имя на момент события хранится только во внутренней таблице KSC).
- Пороги «Состояния защиты» запоминаются на сеанс (не в профиле); карточка компьютера использует 3 и 30 суток.
- Семейства каталога строятся по префиксу названия: продукты одного производителя без общего «основного» (например, TrueConf Client и TrueConf Server) в семейство не объединяются — для них есть выбор всех продуктов производителя.
- Быстрая проверка версий возвращает все строки до `max_rows` (не более 20 000) одним ответом; больше — только фоновым отчётом.
