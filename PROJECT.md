# KAV Checker — текущее состояние проекта

Документ описывает только актуальное состояние. Журнал изменений по датам — [HISTORY.md](HISTORY.md); изменения для пользователей — [CHANGELOG.md](CHANGELOG.md).

## Назначение

Независимый центр аудита и отчётности Kaspersky Security Center (KSC). Подключается к базам Серверов администрирования KSC на Microsoft SQL Server **только для чтения** и даёт: реестр установленного ПО, поиск программ и версий, группировку пакетов по продуктам и веткам (PHP), список компьютеров с выбранными версиями, контроль активности устройств, уязвимости KSC, отчёты XLSX/CSV. Лицензия MIT, репозиторий публичный. Продукт универсален (без данных конкретной организации), ставится в Docker, обновляется из GitHub.

Пользователи: администраторы информационной безопасности и системные администраторы; рабочий инструмент с высокой плотностью данных, используется ежедневно.

## Архитектура

| Сервис (compose) | Технология | Роль |
|---|---|---|
| `web` | nginx unprivileged + React/TypeScript SPA (Vite) | статика, прокси `/api/`, CSP |
| `backend` | Python 3.12, FastAPI, SQLAlchemy async, Alembic | API, вход, роли, источники KSC, данные, отчёты (постановка), настройки, журналы |
| `worker` | тот же образ (`python -m app.worker`) | фоновое формирование отчётов из таблицы `report_jobs` |
| `postgres` | PostgreSQL 16 | внутренняя база |

Базы KSC читаются драйвером pymssql через шаблоны `backend/app/ksc/queries.py` с защитой `guard.py`. Обновления из браузера — через помощника на хосте `scripts/updater.sh` (канал `DATA_ROOT/updater`).

## Важные каталоги и файлы

- `backend/app/` — `main.py` (фабрика), `models.py`, `api/` (маршруты), `auth/` (сессии, роли, LDAP), `ksc/` (адаптер KSC), `reports/` (построитель, экспорт, воркер), `services/` (настройки, аудит, источники, обновления).
- `backend/migrations/` — Alembic (только внутренняя база). `backend/tests/` — pytest (SQLite + синтетический SQL Server).
- `frontend/src/` — `App.tsx` (оболочка, навигация с бегущим индикатором, переключатель источника, меню пользователя), `api.ts`, `styles.css` (дизайн-система: токены обеих тем, компоненты, движение), `components/` (`ui.tsx` — PageHead, Empty, SkelRows, Segmented, Tabs, Spectrum, Dock; Icons, Dialogs, Toast, Common), `pages/` (Dashboard, Software, Hosts, Vulns, Reports, Planned, Login, ChangePassword, Admin + `pages/admin/*`).
- `frontend/public/fonts/` — самостоятельно размещённые шрифты Onest и JetBrains Mono (woff2, кириллица и латиница, лицензии OFL рядом; без CDN).
- `deployment/compose.yml`, `.env.example` — развёртывание. `scripts/` — install, update, rollback, backup, restore, updater, release, ctl, check_private_data.
- `docs/` — установка, администрирование, LDAP, обновления, архитектура, разработчикам; `docs/ksc/` — карта знаний KSC.
- `tests/ksc_synthetic/` — синтетическая база «как KSC» для SQL Server 2022 в Docker.
- `AGENTS.md` — правила для ИИ-агентов.

## Технологии и зависимости

Backend: fastapi, uvicorn, SQLAlchemy 2, asyncpg, alembic, pydantic 2, ldap3, cryptography (AES-GCM), argon2-cffi, pymssql, openpyxl. Frontend: React 19, react-router-dom 7, TypeScript 5, Vite 6; без UI-библиотек, пиктограммы — собственный набор SVG в `components/Icons.tsx` (контур 1.75). Docker Engine + Compose v2.

## Дизайн-система интерфейса

- Направление «приборная панель аудитора»: графитовая боковая панель (`--chrome`), светлое холодное полотно, один акцент — петролевый `--accent` (#0f6a8b; в тёмной теме #5ec8e5), статусы ok/warn/danger, шкала оттенков `--sp-0…7` для версий.
- Шрифты: Onest — интерфейс; JetBrains Mono — только версии, IP-адреса, CVE, регулярные выражения и команды. Числа — `tabular-nums`.
- Токены: радиусы 4/6/8/12, тени с оттенком полотна, длительности и кривые `--ease-out`, `--ease-spring`, `--ease-io`, `--ease-toast`. Темы: «как в системе», светлая, тёмная (`localStorage kc:theme`, атрибут `data-theme`).
- Фирменный элемент — «спектр версий» (`Spectrum`): пропорциональные сегменты веток, наведение подсвечивает строку таблицы, щелчок выбирает ветку; выбор собирается в плавающую панель действий (`Dock`).
- Движение: бегущий индикатор меню, вкладок и сегментов, пружина переключателей и флажков, нажатие кнопок, всплывающие уведомления, состояние «выполняется» на кнопках (`aria-busy`). При `prefers-reduced-motion` остаются только смены прозрачности и цвета.
- Доступность: ссылка «Перейти к содержимому», видимый фокус, ловушка фокуса в окнах, Escape и щелчок снаружи закрывают меню и окна с возвратом фокуса, стрелки во вкладках и списке источников.
- Адаптивность: до 960 px меню — выдвижная панель, до 700 px окна — нижний лист, таблицы прокручиваются по горизонтали.

## Важные настройки

`.env` (вне git): `APP_PUBLIC_URL`, `ALLOWED_ORIGINS`, `DATA_ROOT`, `WEB_BIND_ADDR/WEB_PORT`, `POSTGRES_*`, `APP_MASTER_KEY` (шифрование паролей источников и LDAP), `IMAGE_REPO/IMAGE_TAG`, `GITHUB_REPO`, ограничения `KSC_*`, `REPORT_CONCURRENCY`, `CACHE_TTL_SECONDS`. Настройки в интерфейсе: группы `general` (порог активности, сроки хранения), `ldap`, `reports`.

## Реализованные функции (0.1.0)

- Оболочка: левое меню (выдвижное на узких экранах), верхняя панель с переключателем источника KSC и меню пользователя, темы «как в системе»/светлая/тёмная, страницы 404 и «нет источника».
- Локальные учётные записи, LDAP/LDAPS, роли admin/analyst/viewer, доступ к отдельным источникам, смена пароля, защита от перебора, CSRF.
- Источники KSC: CRUD, диагностика подключения (SQL Server, версия KSC, объекты по функциям, права).
- ПО: реестр KSC (поиск, счётчики установок и компьютеров), группировка по правилам (встроенное PHP), выбор версий/веток, компьютеры по выбору с фильтром активности, сценарии аудита.
- Компьютеры: список с фильтрами и активностью, карточка (сведения, статус KSC, продукты Kaspersky, ПО).
- Уязвимости KSC и пользовательские критерии.
- Отчёты: конструктор, фоновое формирование, отмена, повтор, шаблоны, XLSX/CSV.
- Администрирование: состояние системы, источники, пользователи, LDAP, общие настройки, правила группировки, обновления/откат/резервные копии, журнал событий, журнал действий.

## Известные ограничения

- Разделы «Состояние защиты» и «События безопасности» — описательные заглушки.
- Обновление из браузера не проверено на реальном релизном теге (remote не настроен); LDAP не проверен на реальном каталоге; Windows-авторизация к SQL Server не проверена.
- Нет автоматического получения уязвимостей из внешних источников.
- В страницах осталось около 80 встроенных стилей (`style={{…}}`), в основном ширины полей фильтров; кандидаты на перенос в классы.
- Имена компьютеров с дефисом могут переноситься после дефиса в узких столбцах.
